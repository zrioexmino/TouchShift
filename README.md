# TouchShift

A lightweight Android directional input prototype.

## About

TouchShift is an experimental Android project exploring a floating trigger button that cycles through configurable directional inputs.

## Planned Features

- Floating trigger button
- Configurable directional sequences
- Lightweight user interface
- Android compatibility testing

## Project Status

Early development. Features are planned and have not yet been fully implemented or tested.

## Platform

Android
